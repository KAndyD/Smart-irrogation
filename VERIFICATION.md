# Проверка готового архива

- Полная серия: 80 запусков, 4 метода/конфигурации.
- Число запусков каждого метода: 20.
- Бюджет каждого запуска: 3072 оценок основной целевой функции.
- Проверены сохранённые seed, бюджеты и локальные ссылки Markdown.
- Все численные показатели первого seed совпали с полной серией; время исключено из сравнения.
- Среда: Python 3.12.14, NumPy 2.3.5, Matplotlib 3.10.8, Linux.
